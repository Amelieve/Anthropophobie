# Anthropophobie

Ce site présente la faisabilité d'un *concept d'expérience multimédia* présenté dans le cours *582-501MO Conception d'une expérience multimédia* au collège Montmorency enseigné par Thomas O Fredericks.

## Résumé du projet

Plusieurs mini-jeux avec des mécaniques simples. 4 joueurs, chacun on 3 vies et le but est de survivre jusqu’à la fin. Possibilité de collaborer entre les joueurs pour que tout le monde survive mais plus ancré sur la compétition. 


## Le parcours de l'interacteur

En entrant dans le studio, les joueurs s'installent devant le projecteur en choisissant une manette. Pour démarrer le jeu, les joueurs doivent appuyer simultanément sur un bouton de leur manette respective. Ensuite, une cinématique se lance et expose aux joueurs la cruauté du jeu, en affichant les quatres joueurs équipé d'une bombe chacun. Accompagné d'un message qui indique clairement que le vainceur est le seul survivant. Un compteur sur les bombes affichent un petit "03" qui clignote montrant leur nombre de vies restantes. Après la mise en situation, les joueurs commencent une série de mini jeux qui se joue avec les manettes. Après chaque défaite le dernier classé perd une vie. Au fil des défis, certains sont éliminés jusqu'à ce qu'il ne reste qu'un vainceur. Après la victoire, une cinématique de fin se lance. Par la suite, le jeu retourne au menu de départ ce qui laisse la chance à une nouvelle partie de commencer.

## Comment le projet s'adapte pour un à plusieurs interacteurs

Le jeu reste similaire que ce soit 2,3 ou 4 joueurs avec le principe d'élimination progressif et d'un seul vainceur à la fin. S'il y a seulement un joueur, les mini-jeux qui peuvent deviennent une course contre le monde, cela permet que le joueur peut quand même perdre des vies. 

## Pourquoi ce projet est original ?

Pour commencer, l'esthétique du jeu est unique grâce à son interface industrielle et ses mini jeux sanglants, plongeant le joueur dans un autre monde. De plus, le jeu réunis les joueurs devant un écran créant une ambiance de guerre mais aussi d'alliance contre les autres.
